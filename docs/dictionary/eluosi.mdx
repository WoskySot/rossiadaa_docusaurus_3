## 概括

**俄罗斯帝国**（1721–1917）的通称，也叫沙俄。首都先为圣彼得堡，后迁莫斯科；1917 年二月革命后覆亡。

- 起止：彼得一世称帝 → 尼古拉二世退位
- 相关：[罗曼诺夫王朝](./romanov.mdx)

## 详细说明

这一节只出现在词条页面上，**不会**进入弹窗——弹窗只取「## 概括」到下一个标题之间的内容。

### 名称

「帝俄」是中文语境里对俄罗斯帝国的习惯称呼，强调的是它的帝国体制与皇帝（沙皇）政体，
与「沙俄」「俄国」指的是同一个政治实体。

### 版图

鼎盛时期（19 世纪初）西起波兰、东至阿拉斯加，面积约 2280 万平方公里。
