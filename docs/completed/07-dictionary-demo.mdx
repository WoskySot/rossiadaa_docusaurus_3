本页演示「Dictionary 词条弹窗」：正文里一个**普通的 Markdown 链接**指向 `docs/dictionary/` 下的词条，
构建期就会在链接旁挂一个小窗，内容是词条里作者手写的「## 概括」一节。

## 怎么写

词条文件（`docs/dictionary/<名字>.mdx`）里用一个二级标题 `## 概括` 承载弹窗内容：

- 标记：`## 概括`
- 范围：从这个标题开始，到**下一个同级或更高级标题**为止（再往后的内容只出现在词条页面上）
- 内容：完整 Markdown —— 粗体、链接、列表都可以

正文里**不需要任何新语法**，写一个指向词条的链接就行：`[帝俄](/docs/dictionary/eluosi)`。
链接照常可点，JS 被禁用时它退化成一条普通链接。

## 实际效果

帝国时期的行政机构（见 [帝俄](/docs/dictionary/eluosi)）沿用了彼得一世留下的官制，
其世袭贵族多出自 [罗曼诺夫王朝](/docs/dictionary/romanov)。

同一段里出现两个词条时，把鼠标移到另一个上、或在触屏上点另一个，会**换成它的弹窗**——
同一时刻只留一个。

## 与脚注共存

脚注照旧可用：下面这个编号[^1]弹出的仍是**本文档文末**的注解；
而词条弹窗展示的是**另一篇文档**的内容。两者内容来源不同，却共用同一套弹窗外观与定位算法，
在同一个段落里互不影响。

[^1]: 这是本文档自己的脚注。它与词条弹窗走的是两套内容来源，但共用同一套弹窗。
