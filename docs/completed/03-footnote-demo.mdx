本文是**弹出窗口式脚注**的样例。正文里每个脚注编号都可以**鼠标悬停**、**键盘 Tab 聚焦**，或者在**触屏上点一下**，就地弹出注解内容——不必跳到页面底部；同时底部的标准脚注区依然保留，点编号仍可跳转过去。[^1]

这段是普通正文，没有任何特殊写法：作者只要在需要注解的地方敲一个方括号编号，其余交给编译局自动处理。[^2]

## 多处交叉引用

同一条注解可以在文章里被引用多次。[^3] 被多次引用时，底部的脚注条目会自动多出几个返回箭头。[^3]

不同的注解各有各的编号，弹窗里显示的永远是那一条自己的内容。[^4]

## 注解里也能写标记

注解内容本身支持 Markdown，弹窗里会照常渲染：

- **加粗**、*斜体*、行内代码 `--ifm-color-primary` 都可用；[^5]
- 也可以放链接，例如指向 [编译局总览](/docs/)；[^6]
- 甚至可以放列表，列表项会一起出现在弹窗里。[^7]

## 多段注解

注解也可以是多段的：弹窗里会保持分段，而不是挤成一行。[^8]

## 底部脚注区仍然在

把页面拉到最底部，你会看到标准样式的脚注列表。它是这些弹窗内容的**唯一权威副本**，弹窗只是它的一个"预览窗口"。于是：

- 触屏设备、禁用 CSS 的读者，功能不会坏——点击编号照样跳到注解；[^9]
- 想引用注解本身，直接链接底部条目即可；[^10]
- 打印时弹窗不会出现，底部注解照常打印。

两个方向的跳转都做过专门处理，都不按浏览器的默认方式顶格对齐：

- **点正文里的编号**跳到文末条目时，那条注解会停在**视口正中**，而不是紧贴在吸顶导航栏下面；
- **点文末条目里的 `↩`** 回到正文时，对应的编号同样滚到**视口正中**并短暂高亮——
  否则那么小的一个数字停在页面最上沿，很难在段落里重新找到。

## 怎么在自己的文章里用

写法只有两件事：**正文里写编号引用，文末写编号定义**。完整说明见 [弹出窗口式脚注：写法说明](/docs/completed/footnote-guide)。

---

:::info[技术说明（写给维护者）]

本页的弹窗由本地 rehype 插件 `plugins/footnote-popover/index.js` 在构建时把底部注解**复制**到每个引用旁边，
再由 `src/css/custom.css` 里的 `.fnRef` / `.fnPop` 规则控制显隐。

副本本身是**纯静态**的：插件只在构建期工作、不依赖 hydration。弹窗的几何与外观写在 CSS 基础层，
媒体查询里只留"什么时候显示"——所以指针设备靠 `:hover` / `:focus-within`，触屏靠脚本挂的 `[data-fn-open]`。

"**显示在哪儿**"则两个平台共用同一套实测算法（`src/clientModules/footnotePopoverFit.js`）：
上方优先 → 上方放不下翻到下方 → 水平越界整体平移 → 仍装不下则限高并在内部滚动。
算法只往元素上写两个 CSS 变量和两个状态属性，几何本身留在 CSS 里。

客户端 JS 有三处，都在 `src/theme/Root.js` 挂载、都只挂 document 级委托监听（SPA 换页不用重绑）：

- `src/clientModules/footnoteScrollCenter.js`：两个方向的跳转都改成滚到**视口垂直居中**，加 1.6s 落点高亮；
- `src/clientModules/footnoteTouchPopover.js`：触屏的两段式点击（第一下开弹窗、第二下才跳转）；
- `src/clientModules/footnotePopoverHover.js`：指针设备上的弹窗定位（悬停/聚焦时套用上面那套算法）。

两个弹窗模块的门控查询互为反面，同一时刻只有一个在工作——指针设备上"悬停弹窗、点击即跳转"的行为没变，
变的只是弹窗不再探出视口或被裁掉。

禁用 JS 时功能不坏：弹窗不出现，编号照旧跳到文末注解（退回浏览器原生的顶格对齐）。

:::

[^1]: 这是第一条注解：出现在段落的脚注编号上，演示"最短可用形态"——一行普通文字。

[^2]: 正文本身不需要任何标记，只有编号需要方括号。

[^3]: 同一条注解可以被引用多次。这一条就出现了两次，底部条目会对应长出两个返回箭头。

[^4]: 不同的注解各自独立，弹窗内容不会串台。

[^5]: 注解支持行内标记，`--ifm-color-primary` 是本站的主色变量。

[^6]: 注解里可以有链接，比如 [编译局总览](/docs/)。

[^7]: 注解里可以有列表：

    - 这是第一个列表项；
    - 这是第二个列表项。

[^8]: 多段注解的第一段。

    多段注解的第二段：在源文件里用空行 + 四个空格缩进续写，弹窗里会保持分段。

[^9]: 触屏与禁用 CSS 时的降级行为：禁用脚本时回落到原生"点击跳转"。

[^10]: 底部条目带稳定的 `id`，可以直接引用。
