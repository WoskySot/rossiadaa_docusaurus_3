## 为页脚（Footer）设计品牌配色

**改动文件**：`src/css/custom.css`（仅追加，未动 `docusaurus.config.js` 的 `footer.style: 'dark'`）

**方案**：沿用 Docusaurus 官方文档 “Styling and Layout” 的做法，只改 Infima 的 `--ifm-footer-*` CSS 变量，不硬编码 Infima 内部类。

- 选择器用 `theme-layout-footer.footer`（`ThemeClassNames.layout.footer.container` 的稳定主题类名 + `footer`），优先级 (0,2,0) 高于 Infima 自带的 `.footer--dark` (0,1,0)，不依赖样式表加载顺序。
- 亮色页脚底色 `#320009`（= 亮色模式 `--ifm-color-primary`），与首页 `hero--primary` 同色，形成首尾呼应。
- 暗色页脚底色 `#2a060e`，文字统一用暗色模式主色 `#ffd1b3`（标题/悬停）+ `#f2e0d8`（链接）+ `#c2a49b`（版权）。
- 顶部 1px 暖色细线作分隔：亮色 `rgba(255,209,179,.28)`、暗色 `rgba(255,209,179,.18)`。

**踩坑记录（重要）**：Infima 默认 `--ifm-footer-link-hover-color: var(--ifm-color-primary)`。一旦把页脚背景改成主色，链接悬停就会变成"主色文字压在主色背景上"而完全看不见，必须显式改写 hover 颜色。

**验证**：`docusaurus build` 通过；产物中 `styles.*.css` 内含自定义规则，且位置(77643)在 Infima 的 `.footer--dark`(41269) 之后；HTML 实际输出 `<footer class="theme-layout-footer footer footer--dark">`。

**本项目其他事实**：Docusaurus 3.10.2 / React 19，`respectPrefersColorScheme: true`，`onBrokenLinks: 'throw'`（新增链接要确保有效）。亮色主色 `#320009`（帝俄深酒红），暗色主色 `#ffd1b3`（暖杏）。
